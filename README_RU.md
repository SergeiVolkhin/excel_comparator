# Excel Comparator

Сравнивает два табличных файла — Excel или CSV — по ячейкам и пишет отчёт с найденными различиями.

Работает как настольное приложение (tkinter) или из командной строки. Отчёт сохраняется в `.xlsx` с подсветкой различающихся ячеек и листом сводки, в `.html` с таблицами рядом, либо в `.csv` с колонкой статуса по каждой строке.

## Требования

- Python 3.11 или новее
- pandas, numpy, openpyxl, chardet, python-dateutil
- для окна программы: sv-ttk (оформление Windows 11) и tkinterdnd2 (перетаскивание файлов)

Точные диапазоны версий — в [requirements.txt](requirements.txt). Графическому интерфейсу нужен tkinter: на Windows и macOS он входит в стандартный установщик CPython, на Linux ставится из пакетного менеджера, например `apt install python3-tk`. Если sv-ttk или tkinterdnd2 не загрузятся, окно всё равно откроется: со стандартным оформлением и без перетаскивания.

## Установка

```bash
pip install -r requirements.txt
python main.py
```

Запуск `python main.py` без аргументов открывает графический интерфейс. Для командной строки добавьте `--cli`.

## Использование

### Графический интерфейс

Окно одно, сравнение в три шага:

1. Перетащите два файла из Проводника в окно или нажмите **Выбрать…** на карточках «Первый файл» и «Второй файл». Подходят `.xlsx`, `.xls`, `.csv`, `.tsv` и `.txt`. Файл, брошенный на карточку, попадает в неё; два файла, брошенные на окно, — в обе карточки по порядку. Кнопка **⇄** меняет файлы местами.
2. Нажмите **Сравнить** или Enter.
3. Итог появится в том же окне: зелёная плашка «Данные совпадают» или красная «Есть расхождения» с цифрами. **Открыть отчёт** откроет файл Excel с подсветкой различий, **Показать в папке** — папку с ним.

Переключатель **Порядок строк не важен** включён по умолчанию: строки сопоставляются по содержимому (см. ниже). Выключите его, чтобы сравнивать строки по номеру.

Редкие настройки спрятаны в раскрывающемся блоке **Дополнительно**:

- **Ключевые столбцы** — через запятую, например `dt, idUser`. Поле активно, когда включён «Порядок строк не важен».
- **Игнорировать регистр** и **Игнорировать пробелы по краям**.
- **Пропускать повреждённые строки CSV** — если включить, строки CSV, которые pandas не смог разобрать, отбрасываются, а не прерывают загрузку.
- **Отчёт** — куда сохранить отчёт. По умолчанию рядом с первым файлом, имя `Сравнение.xlsx`; существующий отчёт не перезаписывается — следующий будет `Сравнение (2).xlsx`, `Сравнение (3).xlsx`… Кнопка **Изменить…** задаёт другой путь; расширение выбирает формат (`.xlsx`, `.html`, `.csv`).

Окно оформлено в стиле Windows 11 и само выбирает светлую или тёмную тему по настройке Windows. Последние настройки и папка с файлами запоминаются между запусками. Клавиша F1 или кнопка **?** открывают краткую справку.

Окно всегда сравнивает компаратором `advanced`. Чем отличаются `basic` и `advanced` (оба доступны из кода):

- `basic` ждёт, что обе таблицы одного размера и с одинаковыми именами столбцов. Сравнивает ячейку с ячейкой и завершается ошибкой, если структура расходится.
- `advanced` работает с разным числом строк и разными наборами столбцов. Выравнивает данные и помечает строки, которые есть только в одном файле.

### Сравнение без учёта порядка строк

Обычное сравнение идёт по позиции: первая строка с первой, вторая со второй. Если две выгрузки содержат одни и те же строки в разном порядке, почти все ячейки окажутся «различающимися». Режим без учёта порядка строк (в окне — переключатель **Порядок строк не важен**, в командной строке — `--ignore-row-order`) работает с `basic` и `advanced` и сопоставляет строки по содержимому:

- **Без ключевых столбцов** строки сопоставляются в два прохода. Сначала одинаковые строки целиком. Потом, среди оставшихся, ищется «та же строка, но изменённая»: пара годится, если совпадает не меньше половины столбцов. Совпадение редкого значения (id игрока, сумма) весит больше, чем частого (0, валюта, дата). Если для строки нашлись два равноценных кандидата, она остаётся без пары: лучше «только в файле», чем ложная пара. Такие пары помечаются в отчёте «по сходству».
- **С ключевыми столбцами** строки сопоставляются по ключу, а отличия в остальных столбцах подсвечиваются в отчёте, как при обычном сравнении.
- Повторяющиеся строки сопоставляются по порядку появления: две одинаковые строки против одной — это одна совпавшая и одна «только в первом файле».
- `8000` и `8000.0` равны; пустая ячейка, `NaN` и `None` равны; дата без времени равна той же дате, записанной текстом (`2026-09-01`). Числа, записанные текстом, с числами не сравниваются.

В отчёте строки первого файла идут в исходном порядке, напротив каждой — её пара из второго файла, а строки «только во втором файле» — в конце. На листе **Сводка** появляется блок «Сопоставление строк»: итог (совпадают / есть расхождения), сколько строк совпало, сколько изменённых строк нашли пару (из них по сходству), сколько есть только в одном из файлов, отличается ли порядок, и итоги по числовым столбцам для каждого файла. Суммы считаются через `math.fsum`, поэтому от порядка строк не зависят. Процент схожести округляется вниз: одна различающаяся ячейка на десятки тысяч покажет `99.99%`, а не `100.00%`.

Лист **Расхождения** (второй, сразу после сводки) содержит только строки с отличиями. Изменённая строка занимает две строки листа: из файла 1 и из файла 2. Изменённые ячейки подсвечены, указан номер строки в каждом исходном файле, а в столбце «Что изменилось» записано, например, `Sum_in_from_sum_out: 1000 → 100 (-900)`. Разница для чисел считается как «файл 2 − файл 1», так же, как в итогах по столбцам. Строка без пары занимает одну строку листа. Лист показывает первые 50 000 расхождений, а на листах данных отмечены все.

### Командная строка

```bash
python main.py --cli --file1 prod.xlsx --file2 staging.xlsx --output diff.xlsx
```

В режиме CLI всегда берётся компаратор `advanced`. Флаги:

- `--file1`, `--file2`, `--output` — обязательны вместе с `--cli`.
- `--format {xlsx,html,csv}` — задать формат отчёта вместо определения по расширению.
- `--ignore-case`, `--ignore-whitespace` — то же, что галочки в интерфейсе.
- `--ignore-row-order` — сравнивать без учёта порядка строк (галочка «Без учёта порядка строк»).
- `--key-columns "dt,idUser"` — ключевые столбцы для `--ignore-row-order`; без них строки сопоставляются целиком, а изменённые — по сходству.
- `--csv-encoding ENC` — задать кодировку входа вместо автоопределения через chardet.
- `--csv-delimiter SEP` — задать разделитель вместо автоопределения.
- `--csv-skip-rows N` — пропустить первые N строк каждого CSV.
- `--chunk-size N` — строк в чанке, когда CSV больше 100 МБ (по умолчанию 50000).
- `--csv-on-bad-lines {error,skip,warn}` — `error` прерывает на битой строке (по умолчанию), `skip` молча её отбрасывает, `warn` отбрасывает и пишет в лог число отброшенных.
- `--log-level {DEBUG,INFO,WARNING,ERROR,CRITICAL}`.

CSV с заданным разделителем и кодировкой, с пропуском битых строк:

```bash
python main.py --cli \
    --file1 prod.csv --file2 staging.csv --output diff.csv \
    --csv-delimiter ";" --csv-encoding cp1251 --csv-on-bad-lines skip
```

Две выгрузки отчёта, где строки могут идти в другом порядке, с сопоставлением по дате и игроку:

```bash
python main.py --cli --file1 old.xlsx --file2 new.xlsx --output diff.xlsx \
    --ignore-row-order --key-columns "dt,idUser"
```

## Форматы вывода

Формат определяется расширением выходного файла: `.xlsx`/`.xls` → Excel, `.html`/`.htm` → HTML, `.csv` → CSV, прочее → Excel. Флаг `--format` это переопределяет.

- **Excel** — лист сводки со статистикой (без учёта порядка строк — ещё и блок сопоставления строк), лист «Расхождения» только со строками с отличиями и два листа с исходными данными и подсветкой различающихся ячеек. Столбец «Различия» на обоих листах данных описывает изменение в одном направлении, «файл 1 → файл 2». Ширина столбцов считается по первым 200 строкам. На таблицах больше 20 000 строк форматтер пишет в лог предупреждение с советом взять HTML: поячеечная подсветка на таком объёме замедляется.
- **HTML** — сводка, число различий по столбцам и две таблицы рядом с подсветкой расхождений. Таблицы больше ~1000 строк разбиваются на файлы `_page_N.html` рядом с основным.
- **CSV** — исходные столбцы плюс завершающая колонка `__status__` со значениями `EQUAL`, `MODIFIED`, `ADDED` или `REMOVED`. Строки `ADDED` берут содержимое из второго файла. Кодировка, разделитель и quoting задаются опциями; `diff_only` (через API) убирает строки `EQUAL`.

Для входных CSV и TSV кодировка определяется автоматически (chardet, при неуверенности — UTF-8), разделитель выбирается из `,`, `;`, табуляции и `|`. BOM снимается сам.

## Конфигурация

При первом запуске приложение пишет `config.json` в каталог пользователя:

- Windows: `%APPDATA%\ExcelComparator\config.json`
- Linux / macOS: `~/.config/excel-comparator/config.json`

Там лежат настройки сравнения по умолчанию (окно сохраняет сюда последние выбранные опции и ключевые столбцы), уровень логирования и список недавних файлов — по нему окно открывает диалог выбора в папке последнего файла. Сохранение идёт автоматически; одинаковая запись пропускается, поэтому файл не переписывается на каждое действие.

```json
{
  "comparison": {
    "ignore_case": false,
    "ignore_whitespace": false,
    "ignore_row_order": true,
    "key_columns": [],
    "highlight_color": "FFFF00",
    "max_differences_display": 1000,
    "enable_list_analysis": true,
    "list_separator": ","
  },
  "gui": {
    "window_width": 800,
    "window_height": 600,
    "theme": "default",
    "font_family": "Arial",
    "font_size": 10
  },
  "log_level": "INFO",
  "auto_save_config": true,
  "recent_files": [],
  "max_recent_files": 10
}
```

Логи времени выполнения пишутся в `logs/app.log` в рабочем каталоге.

## Разработка

Создайте виртуальное окружение и поставьте зависимости для разработки:

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux / macOS
pip install -r requirements-dev.txt
```

Проверки перед коммитом:

```bash
python -m pytest tests/ -q --ignore=tests/test_benchmarks.py   # модульные + property + snapshot тесты
python -m pytest tests/ --cov=src --cov-branch                 # покрытие веток, держим >=85%
python -m ruff check src/ tests/
python -m ruff format --check src/ tests/
python -m mypy src/                                            # строгий режим
python -m pytest tests/test_benchmarks.py --benchmark-only     # производительность
```

`ComparisonEngine` (`src/core/engine.py`) связывает сменные части: загрузчики файлов (`src/loaders`), компараторы (`src/comparators`), форматтеры вывода (`src/formatters`) и валидаторы (`src/validators`). Чтобы добавить входной формат или способ сравнения, пишут один класс под нужный интерфейс и регистрируют его в движке.

### Отдельный исполняемый файл

Сборка одного `.exe` под Windows через PyInstaller:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ExcelComparator --icon assets/app.ico ^
    --add-data "src;src" --collect-data sv_ttk --collect-all tkinterdnd2 main.py
```

Результат — `dist/ExcelComparator.exe`. `--collect-data sv_ttk` кладёт в exe файлы темы, `--collect-all tkinterdnd2` — библиотеку перетаскивания; без них окно откроется в стандартном оформлении и без перетаскивания. На Linux / macOS поменяйте разделитель в `--add-data` с `;` на `:`, а перенос строки `^` на `\`.
